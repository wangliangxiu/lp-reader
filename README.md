# The Little Prince · 点词阅读版

英文原版（Katherine Woods 1943 译本）27 章 + 43 幅作者手绘插图 + 全书 2096 个词形的中文释义。
点任意单词查释义并自动发音，段落可朗读、可机翻对照，带生词本。手机、平板、电脑都能开。

在线打开：https://wangliangxiu.github.io/lp-reader/

## 功能

- 点词出中文释义 + 自动朗读；弹窗里 🔊 重听，旁边「美 / 英」切换英式、美式发音
- 顶栏 🎨 换配色：护眼米黄（默认）/ 纸白 / 夜间，选择会记住
- 生词本：☆ 收藏、每词可听、一键复制（制表符分隔，可直接粘 Excel）
- 章节下拉 + ← → 翻章，字号增减，插图点击放大，自动记住读到第几章

## 联网说明

- 点词释义、插图、生词本：离线数据内嵌，打开即用
- 单词发音：取有道词典在线真人音，需联网；没网时自动退回设备自带语音
- 整段朗读：设备自带语音（离线）
- 「译」按钮：免费机翻接口，需联网
- 插图按需加载，首屏约 150 KB
